# البنية والقرارات (نوفمبر 2026)

## 1. المنافسين: شغالين إزاي؟

| الأداة | طريقة الشغل | نقطة الضعف اللي بنستغلها |
|---|---|---|
| ManyChat | Flows + Comment-to-DM بالكلمات المفتاحية، والـ AI إضافة | التسعير على عدد الـ contacts، والـ AI ضعيف |
| NapoleonCat | Auto-moderation بالقواعد + اقتراحات AI في الـ inbox | مش agent بيرد لوحده من knowledge |
| SmartReply / InstantDM / Inrō | AI على الكومنتات + Comment-to-DM، وتسعير flat أو credits | كل أكونت لوحده، مفيش مفهوم "مجموعة أكونتات بعقل واحد" |
| السوق العربي (خمسات/مستقل) | بوتات custom على n8n | مفيش منتج SaaS يفهم اللهجة المصرية ويدير 100 صفحة |

**الفرق عندنا:** Squads (مجموعات أكونتات بتشارك Brain وVoice وذاكرة ردود)، وسلّم توكنز يخلّي أغلب الردود بصفر تكلفة، وفلترة عربي/مصري قبل أي AI.

## 2. ربط Meta: أحسن طريقة

- **طريقتين مع بعض:**
  1. *Facebook Login for Business*: لوجن واحد بيجيب كل الصفحات + الإنستجرام المربوط بيها. دي الأنسب للوكالات و100 أكونت. Page tokens المستخرجة من long-lived user token مبتنتهيش.
  2. *Business Login for Instagram* (`graph.instagram.com`): لإنستجرام من غير صفحة فيسبوك. التوكن بيعيش 60 يوم، والـ worker بيعمل له refresh لوحده.
- **Webhook واحد** لكل الأكونتات، بنتحقق من `X-Hub-Signature-256` (بنقبل سر FB وسر IG الاتنين لأنهم مختلفين)، ونرد 200 فورًا.
- **قيود Meta المطبّقة في الكود:**
  - Private reply: رسالة واحدة لكل كومنت، وخلال 7 أيام.
  - DM: نافذة 24 ساعة من آخر رسالة للعميل. بعدها الرد بيروح drafts، والإنسان يقدر يرد لحد 7 أيام بتاج `HUMAN_AGENT`. **ممنوع البوت يستخدم التاج ده.**
  - Rate limits لكل أكونت: Private replies 750/ساعة (إحنا واقفين عند 700)، Send API 300/ثانية، Conversations 2/ثانية. وفيه حد ذاتي للكومنتات العامة (240/ساعة) عشان الصفحة متبانش spam.
  - Meta بتطلب escalation path لإنسان: ده الـ Inbox وحالة "Needs you".
- **نسخة الـ Graph API** في متغير واحد `META_GRAPH_VERSION` (حاليًا v26.0). كل نسخة بتعيش حوالي سنتين.

## 3. سلّم التوكنز (src/lib/ai/pipeline.ts)

كل رسالة بتطلع على السلّم لحد ما تتحل، وما بتطلعش خطوة زيادة عن اللازم:

| الدرجة | إيه اللي بيحصل | التكلفة |
|---|---|---|
| 0 | تاج صحاب / إيموجي بس / "تم" / spam ← تجاهل، قلب، أو إخفاء | 0 |
| 1 | Instant replies (كلمات مفتاحية متطبّعة عربي: أ/ا، ة/ه، ٣٨/38، بكاااام) | 0 |
| 2 | Exact cache: نفس السؤال بعد التطبيع اتسأل قبل كده في نفس الـ Squad | 0 |
| 3 | Semantic cache: embedding بـ 512 بُعد، وتشابه ≥ 0.93 | ~20 توكن embedding |
| 4 | LLM سريع (`gpt-6-luna`) | رخيص جدًا |
| 5 | LLM أقوى (`gpt-6.1-terra`) للشكاوى أو الـ DMs الطويلة بس | نادر |

**تكبير الـ Prompt caching:** الـ prompt متقسّم جزئين:
- **Static prefix** (القواعد + الـ Voice + الأمثلة + الـ Brain): نفس الـ bytes بالظبط لكل رسائل الـ Squad، ومعاه `prompt_cache_key` لكل Squad. ده اللي بيتقري من الكاش بخصم كبير.
- **Dynamic suffix:** صغير، فيه آخر 6 رسايل + ملخص + الرسالة الجديدة.

لو الـ Brain صغير (≤ 2,500 توكن) بيتحط كله في الـ prefix المتكاش من غير RAG. لو كبير، الحاجات المهمة (Pinned) بس بتتحط في الـ prefix، والباقي بيتجاب بـ pgvector (أعلى 4 قطع، بحد أقصى ~900 توكن).

**حاجات تانية بتوفّر:**
- *Debounce:* 3 رسايل ورا بعض خلال 5 ثواني = نداء AI واحد.
- *ذاكرة ملفوفة:* ملخص ≤ 60 كلمة كل 12 رسالة، بدل ما نبعت تاريخ المحادثة كله.
- *Structured output:* JSON صارم، و`max_output_tokens` صغير.
- *ميزانية شهرية:* لما تخلص، القواعد والكاش بيفضلوا شغالين وأي حاجة تانية بتتحول draft.
- *الثقة:* لو أقل من 0.6 يبقى draft مش رد. الكاش بيتعلّم بس من الردود اللي ثقتها ≥ 0.8 والموديل قال إنها cacheable، يعني مفيهاش أسماء أو بيانات شخصية.

**أسعار OpenAI المستخدمة** (لكل مليون توكن، نوفمبر 2026): luna $0.10 / cached $0.01 / output $0.50، و terra $1.00 / $0.05 / $5.00، و embeddings $0.02. تقدر تعدّلها في `src/lib/ai/models.ts`.

## 4. التحمّل: 100 أكونت وأكتر

- الطابور في Postgres بـ `FOR UPDATE SKIP LOCKED`. تقدر تشغّل أي عدد workers، وكل أكونت بيتعالج على worker واحد بس في نفس الوقت (ترتيب مضمون + rate limits مظبوطة).
- Retry بـ exponential backoff ثم dead-letter. أخطاء Meta النهائية (كومنت اتمسح، صلاحية ناقصة) مبتتعادش. لو التوكن باظ، الأكونت بيتعلّم عليه error.
- Idempotency: Meta بتكرر بعض الـ webhooks، فيه unique index على `(account_id, external_id)`.
- لو القرار اتاخد والإرسال اتأجل بسبب rate limit، القرار بيتحفظ في الـ job، فمبندفعش تمن نفس الفكرة مرتين.
- التوكنز متشفّرة AES-256-GCM.
- `/api/health` بيرجّع backlog الطابور للمراقبة.

## 5. التصميم

- معمول على المرجع اللي بعته: خلفية dotted، أقسام سودا full-bleed، tiles شكلها app-icon طايرة، وكروت collectible.
- **الشخصيات والعناصر 3D:** اتولّدت مخصوص لـ rply على Magnific (موديل GPT 2.6 بخلفية شفافة)، وكلها أصلية مش منقولة.
  - 7 شخصيات: bub (فقاعة كلام زجاج)، heart (قلب كروم)، plane (طيارة ورق مضيئة)، bell (جرس هولوجرافيك)، at (@ جيلي)، phone، lens.
  - 4 عناصر: قلب زجاج، برق كروم، فقاعة typing، شريحة AI.
  - الملفات في `public/art/*.webp` (800px)، ومعاها نسخة `*-head.webp` للأفاتار. الأصول بدقة 2K موجودة في مشروع "rply — brand characters" على حساب Magnific بتاعك.
- **الخطوط:** Hubot Sans للعناوين، Mona Sans للواجهة (الاتنين من GitHub برخصة OFL)، وAlexandria للعربي.
- **الموبايل:** tab bar تحت، الـ Inbox بيقلب بين القايمة والمحادثة، والكروت بتبقى عمودين.
- **حاجات اتجنّبناها عمدًا:** purple gradients، glassmorphism، eyebrows كابيتال، إيموجي كأيقونات، وأي testimonials أو أرقام مفبركة. الأرقام اللي في الصفحة إما قواعد Meta الرسمية، أو حسابات من أسعار OpenAI المنشورة.
